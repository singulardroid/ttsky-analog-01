Block 5: ON / OFF threshold comparators

The last analog stage of the pixel: two single-ended comparators turn the differencing amplifier output into ON and OFF event signals. Their bias voltages are the contrast-threshold knobs of the whole sensor.

1 · Cell cmp_onoff.sch

Two mirror-image single-ended stages share the VDIFF input. ON goes HIGH when VDIFF falls below its threshold (brighter); OFF goes LOW when VDIFF rises above its threshold (darker).

The outputs are analog: a slow ramp of VDIFF gives a steep but not instant edge (slope ≈ −100 V/V). In the pixel each output feeds an inverter, which squares it up and also fixes the OFF polarity (OFF event = output LOW here). Add two sky130_fd_sc_hd__inv_1 cells or two hand-drawn inverters when you build the full pixel; for this lab the raw outputs are more informative.

Monte Carlo add-on (corner=tt_mm)

let run = 0
dowhile run < 30
  reset
  dc Vdiff 0 1.8 0.002
  meas dc t_on  find v(vdiff) when v(on)=0.9  cross=1
  meas dc t_off find v(vdiff) when v(off)=0.9 cross=1
  echo $&run $&t_on $&t_off >> trips_mc.txt
  let run = run + 1
end

Paste the add-on inside the .control block after switching corner.sym to tt_mm. Each reset draws new threshold offsets; trips_mc.txt collects one line per run.

Build order

  1. New schematic → Save As cmp_onoff.sch.
  2. Place the four transistors. The ON pair (Mpon over Mon) and the OFF pair (Moff over Mnoff) are each a PMOS above an NMOS with drains joined. Shift+F flips Mnoff so VOFF arrives from the right.
  3. Wire VDIFF to Mon G and Moff G; VON to Mpon G; VOFF to Mnoff G. lab_pin flags VDD on both PMOS sources and bodies, VSS on both NMOS sources and bodies.
  4. Pins VDD, VSS, VDIFF, VON, VOFF (ipin), ON and OFF (opin). Save, A → cmp_onoff.sym.
  5. New schematic → tb_cmp_onoff.sch: place the symbol, add V1, Vdiff, Von, Voff, one gnd.sym, labels, corner.sym, code_shown.sym.
  6. N, Simulate. Six plot windows and two measured trip points in the terminal.

What it means

Von and Voff are the pixel's contrast-threshold knobs, and the two tables above are their calibration curves. With block 4 parking at 0.63 V, Von = 0.8 V puts the ON threshold 70 mV below the park point and Voff = 0.65 V puts OFF 40 mV above it; divided by the gain of 9 that is 8 mV and 4.5 mV at the photoreceptor, roughly 20 % and 12 % contrast. To reach your 3–5 % target the thresholds have to sit 10–15 mV from the park point, and the Monte Carlo says the random spread alone is 5–7 mV σ. So at 3 % contrast, roughly a third of the pixels in an array would fire on noise or not at all: the trims in the TT bias generator exist to pull Von/Voff per chip, and bigger comparator devices (W = L = 4 µm quarters the σ) are the first thing to change for the high-sensitivity variant.

Chain 3 → 2 → 4 → 5 in one testbench, drive block 1's emulator with a 10 → 20 nA step, and you should see ON go high about 1.5 µs after the step and OFF go low on the way back: that is pixel A minus the handshake.

Carried over from block 1 (so you don't hit it twice)

  • Start xschem from the project's xschem/ folder. Its xschemrc must append $env(PDK_ROOT)/$env(PDK)/libs.tech/xschem to XSCHEM_LIBRARY_PATH, otherwise every sky130_fd_pr/… symbol is "MISSING SYMBOL". set XSCHEM_START_WINDOW {} stops the demo sheet.
  • Two flavours of every transistor. nfet_01v8.sym / pfet_01v8.sym have a B pin you wire; nfet3_01v8.sym / pfet3_01v8.sym have no B pin and take the body net from the text attribute body=VSS / body=VDD. Both netlist the same; the 3-pin one keeps busy schematics clean, the 4-pin one survives a rail rename. If you rename VDD/VSS to the Tiny Tapeout names (VDPWR/VGND), every body= attribute must follow.
  • Pins. ipin, opin, iopin are identical for SPICE; the lab= text is the port name. Rails are ordinary pins inside a cell. Several lab_pin.sym flags with the same lab connect without a wire, which is how the cells below avoid wire crossings; one real pin per rail is still required.
  • Only the testbench has ground. No gnd.sym, sources, corner or control block inside a cell. In the testbench one gnd.sym on the VSS wire makes it SPICE node 0, and V1 makes VDD.
  • Make the symbol with A (Symbol → Make symbol from schematic) after the pins are final; changing a pin later means re-running A, or the testbench reports a pin mismatch. E on an instance descends, Ctrl+E returns.
  • ngspice dc sweeps are linear only. No dec keyword (that is LTspice). For a log picture use linear segments, one per decade, and xlog on the plot.
  • Currents are read through voltage sources. i(vout) works because Vout is a voltage source; a 0 V ammeter.sym gives a named current anywhere else. The x-axis of a current sweep is i-sweep, of a voltage sweep v-sweep.
  • Name internal nets with lab_wire.sym so they are not #net3; inside instance X1 they are reached as v(x1.name).
  • Run: N netlists, "Simulate" runs ngspice in a terminal, the .control block makes the plots, and the ngspice 1 -> prompt accepts setplot dc1, print …, wrdata file.txt …, quit.
  • Files edited outside xschem: close and reopen the schematic (or File → Reload) before saving, or the in-memory copy overwrites the edit.
  • Leakage and temperature. .temp 85 is °C. To see a floor: alter Iin = 0, op, print i(vout). Everything below ~10 pA at a node is leakage territory; pads leak nanoamps, so small currents never leave the chip.
  • A node with no DC path (behind a capacitor, like the differencing amp's input) needs .ic v(x1.x)=0 in the code block, or ngspice parks it wherever gmin says and the first microseconds are nonsense.
  • Mismatch Monte Carlo: set corner=tt_mm on corner.sym (open_pdks adds this section) and loop dowhile … reset … in the control block; each reset draws new random Vth offsets per device.
  • Share a schematic with https://xschem-viewer.com/?file=<GitHub blob URL of the .sch> after pushing. The red X on the repo's "gds" Action is expected until a layout exists in gds/.
